<product_requirements>
FlowSpeak is an Android-first, local-first interactive flowchart utility. It generates living, interactive charts from typed text, with a single graph model shared across 2D, 3D (layered depth within blocks like tabs/subtabs/subflows), and print projections. The application is built using Expo (managed) with TypeScript, prioritizing a mobile-first, responsive, and gesture-driven user experience. Key interactions include drag, pin, recolor (double-tap hold), connect (long-press then tap), zoom (pinch), and rotate (two-finger twist). The MVP focuses on local storage for offline-first capabilities. Node creation supports both typed text and tap-to-create methods. The application includes built-in node types (Task, Decision) with customizable fields, quick-create templates, and future plans for lock/timer protection and app security. Performance targets 400 real-time nodes at 60 FPS. The current implementation has laid the groundwork for the core flowchart creation and backend data persistence.
</product_requirements>
